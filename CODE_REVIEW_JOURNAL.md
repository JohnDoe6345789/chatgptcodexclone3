## Guidelines for Reviewers

1. **Severity Levels**:
   - **Critical**: Security issues, data loss risks, production bugs
   - **Major**: Significant logic errors, performance problems, design issues
   - **Minor**: Code style, documentation, best practices

2. **Review Focus Areas**:
   - Correctness and logic
   - Security and data handling
   - Performance implications
   - Code readability and maintainability
   - Test coverage
   - Documentation accuracy

3. **Constructive Feedback**: Always suggest improvements, not just identify problems

4. **Update Statistics**: Remember to update the statistics table after each review
